Real-time computer vision for game automation

A bot that reads a live game screen with computer vision, finds the cursor, enemies and loot, plans a path, and carries out combat and looting without manual control.

Overview

What this project is

A client wanted a bot for the game The Lord of the Rings Online (LOTRO) that could play the repetitive parts on its own. I built it with OpenCV so that it reads the live game screen, finds the cursor, enemies and lootable objects, and decides what to do next.

It handles path navigation, combat and looting from start to finish, so a character can keep progressing through routine tasks with nobody at the keyboard.

The problem

What needed solving

Repetitive combat and looting can take hours that players would rather spend on the interesting parts of the game. Watching a fast-moving screen for the right cursor state or the next target is also tiring to keep up for long.

Reading the screen with computer vision and driving navigation and combat automatically removes that burden. The same real-time vision and input-automation approach applies to other repetitive, screen-based tasks that would otherwise need constant attention.

My role

What I did

  • Built the bot end to end in Python.
  • Wrote the vision step that reads each captured frame and detects the cursor, enemies and lootable objects.
  • Added path and target planning so the next move is chosen automatically.
  • Connected the decisions to automated input so sequences run without manual control.
Approach

How it works

Screen capture→Detect cursor, enemies, loot→Plan path and target→Automated input

  1. Real-time screen capture

    The bot continuously captures the game screen and applies vision algorithms to detect the cursor, enemies and lootable objects.

  2. Path and target analysis

    NumPy and scikit-image process each frame to work out the best path and pick the next combat or loot target.

  3. Automated input

    PyAutoGUI turns the decision into movement, combat and looting inputs, and the sequence runs without manual control.
