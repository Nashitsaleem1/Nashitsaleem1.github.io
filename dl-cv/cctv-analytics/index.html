Overview

What this project is

I build computer vision services for independent clients. One of them is a CCTV analytics pipeline that reads camera streams over RTSP, detects and tracks what appears in them, and runs as a Python service on the client's own GPU hardware.

A second part of the work generates drone orthomosaics using epipolar geometry, with the results stored in S3-backed storage.

Approach

How it works

  1. Ingest

    Read live camera feeds over RTSP.

  2. Detect

    YOLO11 detects objects in each frame.

  3. Track

    ByteTrack links detections across frames into tracks.

  4. Serve

    The pipeline is packaged as a Python service (FastAPI) for on-prem GPU hardware.

  5. Orthomosaics

    A separate workflow builds drone orthomosaics using epipolar geometry, with results in S3-compatible storage.
