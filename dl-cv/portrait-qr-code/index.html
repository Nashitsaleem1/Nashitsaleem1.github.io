Overview

What this project is

A client wanted QR codes that stand out and carry their brand. I built an interactive GUI application that removes the background from a portrait and blends the person's facial features into a customised QR code.

It combines image processing with creative QR generation, so each code looks distinctive and personal while still scanning reliably.

TypeClient project
InputA portrait photo

Result98% scan success
The problem

What needed solving

Generic QR codes are easy to make but do little to reinforce an identity or stand out from the many identical ones. Designing a personalised code by hand for every person takes time and design skill.

Automating the background removal and the face embedding turns that into a repeatable branding tool, so brands, event organisers and marketing teams can produce distinctive codes at volume without slowing down.

My role

What I did

  • Built the GUI application in Python.
  • Used computer vision to detect and remove the background from uploaded portraits.
  • Wrote the image-processing logic that isolates the facial features and blends them into the QR code.
  • Tuned the result so the personalised code stays reliably scannable.
Approach

How it works

Portrait upload→Background removal→Face embedding→Scannable QR code

  1. Portrait upload

    The user uploads a portrait through the GUI, and computer vision detects and removes the background automatically.

  2. Facial feature embedding

    Python image-processing logic isolates the facial features and blends them into the visual structure of the QR code.

  3. Scannable QR output

    The system renders the customised, branded QR code, which stays fully scannable despite the personalisation.
