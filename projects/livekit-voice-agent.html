How It Works

A closer look at the automated workflow behind the results

1

Secure Sign-In

The user enters a team passcode once, and the server issues a short-lived LiveKit token for a private call room.

2

Voice Conversation

Speech is transcribed in real time, and a turn detector keeps Ava from interrupting mid-sentence.

3

Function Calling

The model picks tools to fetch live data from the read-only company API, the knowledge base, and weather and time services, without inventing figures.

4

Claude Webhook

Ava sends a signed webhook to a Claude skill for deeper analysis, which runs in the background while the conversation continues.

5

Spoken Answer and Hang-Up

Ava replies in a natural voice with a live on-screen transcript, then ends the call and saves it to call history.

6

Always-On Deployment

The agent and call page run as services on an Ubuntu server with HTTPS and restart automatically after crashes or reboots.

Why It Matters

Business Impact

Managers used to check several systems every morning just to start the day. Ava replaces that routine with a short, hands-free spoken brief covering sales, delays, urgent tickets, and meetings, even while driving, and answers follow-up questions in plain language. Longer Claude analyses run in the background so the conversation never stalls. Company data stays protected because Ava can only read it, and every Claude request is signed.
